LibASM - Lenguaje Ensamblador

El objetivo de este proyecto es familiarizarse con el lenguaje ensamblador. El lenguaje ensamblador, a menudo llamado ASM, es un lenguaje de bajo nivel para ordenadores - u otros dispositivos programables - en el cual existe una relación muy fuerte entre el lenguaje y la arquitectura del dispositivo.
